## 📌 Overview

This repository documents my learning journey and practical experience during my internal **Data Engineering Training**.

The training focused on understanding Data Warehousing concepts, Data Modeling, SQL development, and ETL processes using **Oracle SQL Developer** and **Informatica Intelligent Cloud Services (IICS)**.

Throughout the training, I gained both theoretical knowledge and hands-on experience in designing data models, transforming data, and building ETL workflows.

---

## 📚 Topics Covered

### 🏛️ 1. Data Warehousing Concepts

- Understanding the differences between **Data Warehouse, Data Mart, and Data Vault**.
- Learning how each architecture works and when to use it.
- Exploring different Data Mart architectures.
- Understanding the role of Data Warehousing in Business Intelligence and Analytics.

### 📊 2. Data Modeling

- Understanding the differences between Fact Tables and Dimension Tables.
- Exploring different types of Fact Tables and their business purposes.
- Learning different types of Dimension Tables and when to use each.
- Understanding Star Schema and Snowflake Schema.
- Exploring Data Vault modeling concepts:
  - Hubs
  - Links
  - Satellites

### 🔄 3. Slowly Changing Dimensions (SCD)

- Understanding different SCD types.
- Learning how each type handles historical data changes.
- Identifying when to use each SCD type.
- Implementing SCD logic in ETL workflows.

### 💻 4. SQL & Oracle SQL Developer

Worked with Oracle SQL Developer to practice SQL queries and database operations, including:

- Creating and modifying database tables.
- Writing SQL queries and performing different types of JOINs.
- Data manipulation and transformation.
- Working with Primary Keys and Foreign Keys.
- Using SQL queries to prepare and validate data for ETL processes.

### ⚙️ 5. Informatica – ETL Development

Gained hands-on experience with **Informatica Intelligent Cloud Services (IICS)** for designing and implementing ETL workflows.

Practiced different transformations and components:

| Transformation | Purpose |
|---|---|
| 🔍 Lookup | Retrieving matching records from reference data |
| 🔗 Joiner | Joining data from different sources |
| 🔀 Union | Combining multiple data pipelines |
| 🚦 Router | Routing records based on specified conditions |
| 🔄 Normalizer | Transforming denormalized data into normalized structures |
| 💾 SQL Transformation | Executing SQL operations within ETL workflows |

Also explored different integration approaches and **iPaaS (Integration Platform as a Service)** concepts and their use cases.
